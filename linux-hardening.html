Linux Hardening & Servicos

Configuracoes do subsistema PAM, politicas de senhas, auditoria rsyslog e reforco do servico SSH.

1. Complexidade de Passwords (/etc/security/pwquality.conf)

Editar o ficheiro de configuracao com sudo nano /etc/security/pwquality.conf:

Configuracao pwquality.conf 
minlen = 14
minclass = 3
usercheck = 1

2. Bloqueio de Contas (/etc/security/faillock.conf)

Editar o ficheiro com sudo nano /etc/security/faillock.conf:

Configuracao faillock.conf 
deny = 5
unlock_time = 900
fail_interval = 900

(Valores definidos em segundos: 900s = 15 minutos)

3. Validade e Historico de Passwords

Validade Maxima (90 Dias)

Editar /etc/login.defs e ajustar:

login.defs 
PASS_MAX_DAYS   90

Para aplicar imediatamente a um utilizador existente:

Comando chage 
sudo chage -M 90 <utilizador>

Historico de Passwords (30 Passwords)

Editar /etc/pam.d/common-password e adicionar a linha do modulo pam_pwhistory.so:

Linha para common-password 
password required pam_pwhistory.so remember=30 use_authtok

4. Auditoria de Logs com Rsyslog (/etc/rsyslog.d/50-security.conf)

Criar ou editar o ficheiro com sudo nano /etc/rsyslog.d/50-security.conf:

Regras de Log de Seguranca 
# Logs de cron jobs com prioridade exata warning
cron.=warning    /var/log/cron_warn.log

# Logs de users com prioridade igual ou superior a notice
user.notice      /var/log/user_filtered.log

Validar e reiniciar o servico rsyslog:

Comandos de Reinicio do Servico 
sudo systemctl restart rsyslog
sudo systemctl status rsyslog

5. Restricao de Acesso SSH (/etc/ssh/sshd_config)

Editar com sudo nano /etc/ssh/sshd_config e adicionar no final do ficheiro:

Regras de Acesso SSH 
AllowUsers Jane
AllowGroups Monitors

Validar sintaxe e reiniciar o servico com seguranca:

Validacao e Reinicio do SSH 
sudo sshd -t && sudo systemctl restart ssh
