Linux, PAM e Apache

1. Complexidade PAM

/etc/security/pwquality.conf

minlen = 14
minclass = 3
usercheck = 1

2. Bloqueio e validade

/etc/security/faillock.conf

deny = 5
unlock_time = 900
fail_interval = 900

/etc/login.defs e validade de utilizadores:

PASS_MAX_DAYS   90

sudo chage -M 90 <utilizador>
sudo chage -W 14 <utilizador>

3. Rsyslog e SSH

/etc/rsyslog.d/50-security.conf

cron.=warning    /var/log/cron_warn.log
user.notice      /var/log/user_filtered.log

sudo systemctl restart rsyslog
sudo systemctl status rsyslog

/etc/ssh/sshd_config

AllowUsers <utilizador>
AllowGroups <grupo>

sudo sshd -t
sudo systemctl restart ssh

4. Apache

sudo apt update
sudo apt install apache2 -y
sudo systemctl enable --now apache2
sudo ufw allow 80/tcp
