# WSP27 - CyberSecurity Lab Cheat Sheet

O projeto é agora um site de consulta numa única página. Para abrir durante o laboratório, faça duplo clique em [`index.html`](./index.html) ou abra-o no navegador.

Inclui navegação por áreas, pesquisa local, comandos copiáveis, geradores de configuração Windows/Linux e os scripts em [`scripts/`](./scripts/).

Não é necessário instalar dependências nem iniciar um servidor.
