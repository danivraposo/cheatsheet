Rede e Partilhas

1. Samba

sudo apt install samba -y
sudo smbpasswd -a <utilizador>
sudo systemctl enable --now smbd

/etc/samba/smb.conf

[private]
   path = /srv/samba/private
   read only = no
   valid users = <utilizador>
   browseable = yes

2. Permissões Share e NTFS

  1. Abra as propriedades da pasta, Sharing, Advanced Sharing e ative a partilha.
  2. Em Share Permissions, atribua apenas o acesso necessário.
  3. Na aba Security, replique a intenção no NTFS.
  4. Remova grupos genéricos quando não forem necessários e valide com uma conta de teste.
