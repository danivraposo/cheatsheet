Windows Hardening & GPO

            
Políticas locais, auditoria avançada e gestão de acessos remotos.

            
1. Passwords e Account Lockout

            
PowerShell / CMD
net accounts /minpwlen:14 /maxpwage:90 /uniquepw:20 /lockoutthreshold:5 /lockoutduration:15 /lockoutwindow:15

            
Bypass temporário da política de execução
Set-ExecutionPolicy -Scope Process Bypass -Force

            
2. Consolas e caminhos úteis

            
    
                
  • Política de Segurança Local: Win + R → secpol.msc
    • 
                
  • Group Policy no Domain Controller: Win + R → gpmc.msc
    • 
                
  • Password Policy: Security Settings → Account Policies → Password Policy
    • 
                
  • Account Lockout: Security Settings → Account Policies → Account Lockout Policy
    • 
            

            
3. Auditoria e Event IDs

            
Em Advanced Audit Policy Configuration → System Audit Policies, ative Success e Failure para Policy Change, Sensitive Privilege Use e Process Creation.

            
Eventos relevantes
# Tentativas de login falhadas
Get-WinEvent -FilterHashtable @{LogName='Security'; Id=4625}

# Criação de utilizadores
Get-WinEvent -FilterHashtable @{LogName='Security'; Id=4720}

# Instalação de novos serviços
Get-WinEvent -FilterHashtable @{LogName='System'; Id=7045}

            
4. RBAC, grupos e acessos

            
Grupos locais
New-LocalGroup -Name "Monitors"
Add-LocalGroupMember -Group "Remote Desktop Users" -Member "Jane"
Add-LocalGroupMember -Group "Remote Management Users" -Member "John"
Add-LocalGroupMember -Group "Performance Monitor Users" -Member "Monitors"

        


        

            
Linux Hardening & Serviços

            
Configuração de PAM, validade de passwords, rsyslog e SSH.

            
1. Complexidade de passwords /etc/security/pwquality.conf

            
pwquality.conf
minlen = 14
minclass = 3
usercheck = 1

            
2. Bloqueio de contas /etc/security/faillock.conf

            
faillock.conf (segundos)
deny = 5
unlock_time = 900
fail_interval = 900

            
3. Validade e histórico

            
/etc/login.defs e utilizador existente
PASS_MAX_DAYS   90

sudo chage -M 90 <utilizador>

            
/etc/pam.d/common-password
password required pam_pwhistory.so remember=30 use_authtok

            
4. Auditoria com Rsyslog

            
/etc/rsyslog.d/50-security.conf
cron.=warning    /var/log/cron_warn.log
user.notice      /var/log/user_filtered.log

sudo systemctl restart rsyslog
sudo systemctl status rsyslog

            
5. Restrição de acesso SSH

            
/etc/ssh/sshd_config
AllowUsers Jane
AllowGroups Monitors

sudo sshd -t
sudo systemctl restart ssh

        


        

            
Partilhas de Rede & Permissões

            
Samba, partilhas Windows, permissões e testes de conectividade.

            
1. Samba no Linux

            
Instalação e credenciais
sudo apt install samba -y
sudo smbpasswd -a Jane
sudo smbpasswd -a John

            
/etc/samba/smb.conf
[public]
   path = /home/aluno/Desktop/public
   read only = yes
   guest ok = no
   browseable = yes

[private]
   path = /home/aluno/Desktop/private
   read only = no
   valid users = Jane, John
   read list = Jane
   write list = John
   browseable = yes

sudo systemctl restart smbd

            
2. Partilhas Windows: Share + NTFS

            
    
                
  1. Botão direito na pasta → Properties → Sharing → Advanced Sharing.
    2. 
                
  2. Ative Share this folder e abra Permissions.
    3. 
                
  3. public: Authenticated Users apenas com Read.
    4. 
                
  4. private: Jane com Read, John com Change + Read; remova Everyone.
    5. 
                
  5. Na aba Security, replique as permissões no NTFS.
    6.

Scripts Forenses & Triage Rápida

            
Atenção: guarde os scripts numa pasta scripts no Ambiente de Trabalho da máquina Windows: C:\Users\<User>\Desktop\scripts\.

            
1. PowerShell: inventory.ps1

            
Windows triage
# =========================================================
# Script Forense - Windows Triage (WorldSkills)
# =========================================================

Write-Host "=== 1. LISTA DE ADMINISTRADORES LOCAIS ===" -ForegroundColor Cyan
Get-LocalGroupMember -Group "Administrators" | Select-Object Name, PrincipalSource

Write-Host "`n=== 2. SESSÕES RDP ATIVAS ===" -ForegroundColor Cyan
qwinsta

Write-Host "`n=== 3. SERVIÇOS DO WINDOWS ===" -ForegroundColor Cyan
Get-Service | Select-Object Name, DisplayName, Status, StartType

            
Executar
Set-ExecutionPolicy -Scope Process Bypass -Force
.\inventory.ps1

            
2. Bash: inventory.sh

            
Linux triage
#!/bin/bash

# =========================================================
# Script Forense - Linux Triage (WorldSkills)
# =========================================================

echo "================================================="
echo "=== 1. CONTEÚDO DO FICHEIRO /etc/hosts ==="
echo "================================================="
cat /etc/hosts

echo -e "\n================================================="
echo "=== 2. PROCESSOS ATIVOS NO SISTEMA ==="
echo "================================================="
ps aux

echo -e "\n================================================="
echo "=== 3. CONEXÕES DE REDE ABERTAS E PORTAS ==="
echo "================================================="
ss -tulnp

            
Executar no Linux
chmod +x inventory.sh
./inventory.sh
