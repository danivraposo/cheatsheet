Scripts Forenses & Triage Rapida

Scripts automatizados de recolha de evidencias e levantamento de estado dos sistemas operacionais Windows e Linux.

Atencao a Prova: Os scripts desenvolvidos deverao ser guardados dentro de uma pasta chamada scripts no Ambiente de Trabalho da maquina Windows (ex: C:\Users\<User>\Desktop\scripts\).

1. Script PowerShell (C:\Users\<User>\Desktop\scripts\inventory.ps1)

Guarde o seguinte codigo no ficheiro inventory.ps1:

Codigo inventory.ps1 
# =========================================================
# Script Forense - Windows Triage (WorldSkills)
# =========================================================

Write-Host "=== 1. LISTA DE ADMINISTRADORES LOCAIS ===" -ForegroundColor Cyan
Get-LocalGroupMember -Group "Administrators" | Select-Object Name, PrincipalSource

Write-Host "`n=== 2. SESSOES RDP ATIVAS ===" -ForegroundColor Cyan
qwinsta

Write-Host "`n=== 3. SERVICOS DO WINDOWS ===" -ForegroundColor Cyan
Get-Service | Select-Object Name, DisplayName, Status, StartType

Para testar a execucao na consola PowerShell:

Execucao PowerShell 
Set-ExecutionPolicy -Scope Process Bypass -Force
.\inventory.ps1

2. Script Bash (C:\Users\<User>\Desktop\scripts\inventory.sh ou Linux)

Guarde o seguinte codigo no ficheiro inventory.sh:

Codigo inventory.sh 
#!/bin/bash

# =========================================================
# Script Forense - Linux Triage (WorldSkills)
# =========================================================

echo "================================================="
echo "=== 1. CONTEUDO DO FICHEIRO /etc/hosts ==="
echo "================================================="
cat /etc/hosts

echo -e "\n================================================="
echo "=== 2. PROCESSOS ATIVOS NO SISTEMA ==="
echo "================================================="
ps aux

echo -e "\n================================================="
echo "=== 3. CONEXOES DE REDE ABERTAS E PORTAS ==="
echo "================================================="
ss -tulnp

Para atribuir permissao de execucao e testar no Linux:

Execucao Bash 
chmod +x inventory.sh
./inventory.sh
