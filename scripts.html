Scripts Forenses

Execute os scripts com as permissões adequadas e guarde os resultados numa pasta de evidências.

1. PowerShell - inventário Windows

Write-Host "=== ADMINISTRADORES LOCAIS ===" -ForegroundColor Cyan
Get-LocalGroupMember -Group "Administrators" | Select-Object Name, PrincipalSource

Write-Host "`n=== SESSÕES RDP ===" -ForegroundColor Cyan
qwinsta

Write-Host "`n=== SERVIÇOS ===" -ForegroundColor Cyan
Get-Service | Select-Object Name, DisplayName, Status, StartType

Write-Host "`n=== CONEXÕES ===" -ForegroundColor Cyan
Get-NetTCPConnection | Select-Object LocalAddress, LocalPort, RemoteAddress, RemotePort, State

Executar: Set-ExecutionPolicy -Scope Process Bypass -Force; .\inventory.ps1

2. Bash - inventário Linux

#!/bin/bash
set -u

echo "=== HOSTS ==="
cat /etc/hosts

echo "=== PROCESSOS ==="
ps aux

echo "=== PORTAS E CONEXÕES ==="
ss -tulnp

echo "=== UTILIZADORES LIGADOS ==="
who

Executar: chmod +x inventory.sh && ./inventory.sh
