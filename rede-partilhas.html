Partilhas de Rede & Permissoes

Configuracao de servidores de partilha (Samba e Windows SMB), listas de controlo de acesso e diagnostico de rede.

1. Servidor Samba no Linux (/etc/samba/smb.conf)

Pre-requisitos

Instalacao do servico e criacao de credenciais Samba:

Instalacao e Senhas Samba 
sudo apt install samba -y
sudo smbpasswd -a Jane
sudo smbpasswd -a John

Configuracao do Ficheiro (/etc/samba/smb.conf)

Adicionar as definicoes de partilha ao final do ficheiro /etc/samba/smb.conf:

Blocos public e private 
[public]
   path = /home/aluno/Desktop/public
   read only = yes
   guest ok = no
   browseable = yes

[private]
   path = /home/aluno/Desktop/private
   read only = no
   valid users = Jane, John
   read list = Jane
   write list = John
   browseable = yes

Reiniciar servico Samba:

Reiniciar Daemon smbd 
sudo systemctl restart smbd

2. Permissoes de Partilha no Windows (Share + NTFS)

Estrutura Exigida

  • public: Todos os utilizadores autenticados apenas com permissao de leitura (Read).
  • private: Jane com leitura (Read), John com leitura e escrita (Change), restantes utilizadores sem acesso.

Configuracao Passo a Passo (Interface Grafica)

  1. Clique com o botao direito na pasta pretendida > Properties > Sharing > Advanced Sharing.
  2. Marque a opcao Share this folder > Clique no botao Permissions:
    • public: Adicionar Authenticated Users → apenas marcar Read.
    • private: Adicionar Jane (Read) e John (Change e Read). Remover o grupo Everyone.
  3. Aceda ao separador Security (Permissoes NTFS) e configure exatamente as mesmas permissoes para que a regra mais restritiva nao bloqueie o acesso pretendido.

3. Diagnostico e Testes de Conectividade de Rede

Windows (PowerShell)

Verificar IP, Gateway e DNS 
Get-NetIPConfiguration
Testar Conexao a Porta Remota (ex: porta 80) 
Test-NetConnection 192.168.27.20 -Port 80
Listar Portas Locais em Escuta 
Get-NetTCPConnection -State Listen | Select-Object LocalAddress, LocalPort, OwningProcess

Linux (Bash)

Listar Portas Abertas e Processos (ss) 
ss -tulnp
Testar Resolucao DNS (nslookup) 
nslookup dc.wsp27.pt
Testar Conectividade a Porta via Netcat 
nc -zv 192.168.27.20 80
