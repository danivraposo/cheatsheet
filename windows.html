2. Active Directory e políticas de domínio (GPO)

        

            
            
        

        

            
            
Import-Module ActiveDirectory

New-ADOrganizationalUnit -Name "HealthSec" -Path "DC=wsp27,DC=pt"
New-ADGroup -Name "Monitors" -GroupScope Global -GroupCategory Security -Path "OU=HealthSec,DC=wsp27,DC=pt"

$pw = Read-Host "Password inicial" -AsSecureString
New-ADUser -Name "Jane" -SamAccountName "Jane" -UserPrincipalName "Jane@wsp27.pt" -Path "OU=HealthSec,DC=wsp27,DC=pt" -AccountPassword $pw -Enabled $true
New-ADUser -Name "John" -SamAccountName "John" -UserPrincipalName "John@wsp27.pt" -Path "OU=HealthSec,DC=wsp27,DC=pt" -AccountPassword $pw -Enabled $true
Add-ADGroupMember -Identity "Monitors" -Members "Jane"

gpupdate /force

4. GPOs restritivas, bloqueio Admin e DNS (DC)

        

            
            
        

        

            
            
# 1. Criar registo DNS (A) para intranet/portal
Add-DnsServerResourceRecordA -Name "portal" -ZoneName "wsp27.pt" -IPv4Address "192.168.100.30"

# 2. Forçar e verificar políticas aplicadas no cliente
gpupdate /force
gpresult /r

        

        

            
    
                
  1. Bloquear conta Administrador: abrir gpmc.msc, editar Default Domain Policy e ativar Allow Administrator account lockout em Account Lockout Policy.
    2.

5. IIS avançado: HTTPS, redirect e HSTS

        

            
            
        

        

            
            
# 1. Criar certificado autoassinado
New-SelfSignedCertificate -DnsName "wsp27.pt", "www.wsp27.pt" -CertStoreLocation "cert:\LocalMachine\My"

# 2. Abrir porta 443 (HTTPS) na firewall
New-NetFirewallRule -DisplayName "HTTPS Inbound" -Direction Inbound -Protocol TCP -LocalPort 443 -Action Allow

        

        

            
    
                
  1. Criar certificado: abrir inetmgr, selecionar o servidor, abrir Server Certificates e escolher Create Self-Signed Certificate.
    2. 
                
  2. Ativar HTTPS: em Default Web Site > Bindings, adicionar o tipo https, porta 443 e selecionar o certificado.
    3. 
                
  3. Ativar HSTS: em Default Web Site > HSTS, ativar, definir Max-Age como 31536000, incluir subdomínios e redirecionar HTTP para HTTPS.
    4. 
            

        

    


    

        
6. Firewall do Windows: pings (ICMP), portas e perfis

        

            
            
        

        

            
            
# 1. Permitir ping (ICMPv4 Echo Request)
New-NetFirewallRule -DisplayName "Permitir Ping IPv4" -Direction Inbound -Protocol ICMPv4 -IcmpType 8 -Action Allow

# 2. Bloquear ping, se o hardening de ICMP for necessário
Set-NetFirewallRule -DisplayName "Permitir Ping IPv4" -Action Block

# 3. Abrir portas comuns (RDP 3389 e SMB 445)
New-NetFirewallRule -DisplayName "Permitir RDP" -Direction Inbound -Protocol TCP -LocalPort 3389 -Action Allow
New-NetFirewallRule -DisplayName "Permitir SMB" -Direction Inbound -Protocol TCP -LocalPort 445 -Action Allow

# 4. Ativar a Firewall nos três perfis
Set-NetFirewallProfile -Profile Domain,Private,Public -Enabled True

        

        

            
    
                
  1. Execute wf.msc para abrir Windows Defender Firewall with Advanced Security.
    2. 
                
  2. Em Inbound Rules, procure File and Printer Sharing (Echo Request - ICMPv4-In) e ative ou desative a regra.
    3. 
                
  3. Para criar uma regra de porta, escolha New Rule > Port, indique o protocolo e a porta, permita a ligação e selecione os perfis.
    4. 
                
  4. Confirme que os perfis Domain, Private e Public estão ativos.
    5. 
            

        

    


    

        
7. FTP Hardening no IIS (WINSRV: porta 4021 e FTPS)

        

            
            
        

        

            
            
# 1. Instalar FTP Server e criar certificado
Install-WindowsFeature Web-Ftp-Server -IncludeManagementTools
New-SelfSignedCertificate -DnsName "ftp.healthsec.pt" -CertStoreLocation "cert:\LocalMachine\My"

# 2. Abrir porta 4021 na Firewall
New-NetFirewallRule -DisplayName "FTPS Porta 4021" -Direction Inbound -Protocol TCP -LocalPort 4021 -Action Allow

        

        

            
    
                
  1. Abra inetmgr, clique com o botão direito em Sites > Add FTP Site e defina a pasta física.
    2. 
                
  2. Em Binding, altere a porta para 4021.
    3. 
                
  3. Em SSL, selecione Require SSL e o certificado criado.
    4. 
                
  4. Em Authentication, ative Basic, desative Anonymous e atribua as permissões necessárias.
    5. 
                
  5. Abra a porta TCP 4021 na Firewall através de wf.msc.
    6. 
            

        

    


    

        
8. Firewall do DC por IP específico

        

            
            
        

        

            
            
# Substituir <IP_LINSRV> pelo IP real do Ubuntu
New-NetFirewallRule -DisplayName "Permitir Ping de LINSRV" -Direction Inbound -Protocol ICMPv4 -IcmpType 8 -RemoteAddress "<IP_LINSRV>" -Action Allow
New-NetFirewallRule -DisplayName "Bloquear Saida para LINSRV" -Direction Outbound -RemoteAddress "<IP_LINSRV>" -Action Block

        

        

            
    
                
  1. Abra wf.msc.
    2. 
                
  2. Em Inbound Rules > New Rule > Custom, selecione ICMPv4 e adicione apenas o IP do LINSRV em Scope.
    3. 
                
  3. Em Outbound Rules > New Rule > Custom, selecione todos os programas e bloqueie o IP do LINSRV em Scope.
    4.
